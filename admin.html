Status Integrasi Google Sheets & AdminLTE

Backend Admin ini menggunakan template profesional AdminLTE dengan fungsionalitas penuh yang terhubung secara seamless ke Google Sheets dan Google Apps Script REST API.

Pencegahan Duplikasi Aktif
Setiap sinkronisasi Football API otomatis memeriksa ID eksternal (external_match_id) untuk memastikan jadwal resmi tidak terduplikasi.

Panduan AdminLTE

  • Gunakan sidebar kiri untuk navigasi cepat antar menu pengelolaan.
  • Klik tombol Skor di tabel laga untuk cepat memperbarui skor akhir.
  • Semua perubahan langsung disimpan ke database Google Sheets.

Pengaturan API-Football (api-football.com)

ID Resmi PERSIB di API-Football adalah 854.
Gunakan tahun mulai musim (contoh: 2024 untuk 2024/2025).
Penyimpanan API Key (api-football.com):

Demi keamanan, API Key disimpan di Script Properties Google Apps Script (Property: FOOTBALL_API_KEY). Anda juga dapat menjalankan fungsi setFootballApiKey() di editor Apps Script.

Trigger Manual

Jalankan pengambilan jadwal, status, dan pembaruan skor langsung dari Football API feed tanpa menunggu jadwal otomatis.

Fitur Pencegahan Duplikasi:
Sistem memeriksa external_match_id sebelum menulis ke sheet matches. Jadwal yang sudah ada hanya akan diperbarui status dan skornya.
