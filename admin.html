Status Integrasi Google Sheets

Aplikasi ini dirancang untuk bekerja seamless dengan Google Sheets sebagai database relational dan Google Apps Script sebagai backend REST API. Semua penambahan, pembaruan skor, dan sinkronisasi tersimpan permanen.

Pencegahan Duplikasi Aktif
Setiap sinkronisasi Football API otomatis memeriksa ID eksternal (external_match_id) untuk memastikan jadwal resmi tidak terduplikasi.
Panduan Singkat
  • Klik Skor di baris tabel untuk cepat memasukkan skor akhir laga.
  • Semua waktu pertandingan menggunakan format WIB (Asia/Jakarta).
  • Ekspor backup data sewaktu-waktu di menu Database Tools.
  • Deploy script Google Apps Script di folder google-apps-script/ untuk production.

Trigger Manual

Jalankan pengambilan jadwal, status, dan pembaruan skor langsung dari Football API feed tanpa menunggu jadwal otomatis.

Fitur Pencegahan Duplikasi:
Sistem memeriksa external_match_id sebelum menulis ke sheet matches. Jadwal yang sudah ada hanya akan diperbarui status dan skornya.
