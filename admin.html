Status Integrasi Google Sheets & Football API

Aplikasi ini terhubung secara langsung dengan Google Sheets sebagai relational database dan Google Apps Script Web App sebagai API service. Semua entitas (pertandingan, skor, tim, stadion, kompetisi) tersimpan terstruktur dan dapat diekspor sewaktu-waktu.

Pencegahan Duplikasi Otomatis
Setiap sinkronisasi Football API otomatis memeriksa ID eksternal (external_match_id) untuk memastikan jadwal resmi tidak terduplikasi.
Pratinjau Website Utama

Panduan Singkat AdminLTE

  • Gunakan tombol Skor di baris tabel untuk cepat memperbarui skor akhir laga.
  • Format waktu kick-off menggunakan standar WIB (Asia/Jakarta).
  • Menu Database Tools menyediakan fitur ekspor backup format JSON.
  • Script Google Apps Script tersedia di folder google-apps-script/Code.gs.

Pengaturan API-Football (api-football.com)

ID Resmi PERSIB Bandung di API-Football adalah 854.
Tahun mulai musim (contoh: 2024 untuk 2024/2025).
Penyimpanan API Key (api-football.com):

API Key disimpan dengan aman di Script Properties Google Apps Script (Property Name: FOOTBALL_API_KEY). Anda juga dapat menjalankan fungsi setFootballApiKey() di editor Apps Script.

Trigger Manual Sync

Jalankan pengambilan jadwal, status, dan pembaruan skor langsung dari Football API feed tanpa menunggu jadwal otomatis.

Fitur Pencegahan Duplikasi:
Sistem memeriksa external_match_id sebelum menulis ke sheet matches. Jadwal yang sudah ada hanya akan diperbarui status dan skornya.
