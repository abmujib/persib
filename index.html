Dokumentasi REST API JSON PERSIB Bandung

Sediakan integrasi jadwal, skor live, dan statistik resmi PERSIB Bandung ke aplikasi web, mobile (Flutter/React Native), atau bot tanpa API key.

Daftar Endpoint REST API
GET /api/v1/schedule
Semua jadwal & hasil pertandingan PERSIB Bandung.
GET /api/v1/next-match
Satu jadwal pertandingan terdekat berikutnya.
GET /api/v1/results
Hasil pertandingan yang telah selesai (FINISHED).
GET /api/v1/statistics
Ringkasan performa tim (poin, win rate, gol).
GET /api/v1/teams
Daftar tim lawan dan logo resmi.
GET /api/v1/competitions
Daftar kompetisi resmi terdaftar.
